# 地缘推演台 — 历史回溯版 V2

> 地缘政治飞行模拟器：用当时已知的信息做判断，然后看历史实际怎么走的。  
> **事后诸葛亮是廉价的，事前判断才是真功夫。**

---

## 这是什么

一个基于米塞斯行动学（Praxeology）的地缘政治分析工具，通过**历史回溯**的方式训练你的分析能力：

1. 选择一个经典地缘博弈场景（古巴导弹危机、海湾战争、克里米亚危机）
2. 进入 **🔒 时间锁定模式**——你只能看到决策时**当时已知**的信息，无法偷看结果
3. 通过**引导题**逐层推演：行为体分析 → 底盘约束 → 军事制度 → 路径预判
4. 点击 **🔓 揭示历史**，看到你的推演 vs 历史实际的并排对比

## 核心理念

### 行动学第一公理：个体的人行动

"中国不会行动"——做决策的是具体的人。"日本不会行动"——做决策的是内阁总理大臣。

不分析国家，分析**做决策的人**：
- 权力基础（选举/党机器/军方/世袭）
- 制度约束（选举周期/派系平衡/任期限制）
- 决策风格（审慎/冒险/意识形态驱动/务实/反应型）
- 个人目的与国家目的的偏差

### 主体性建构：国家怎么定义"我是谁"

- **整合式**：能容纳矛盾，分层管理目的（如：中国的"民族复兴"叙事）
- **摆荡式**：新身份=否定旧身份，不能渐变只能弹射（如：日本的"脱亚入欧"）
- **互锁式**：通过否定对方来定义自己（如：以色列与巴勒斯坦互为镜像）
- **交易式**：用资源购买身份，从未真正建构（如：沙特用石油美元购买影响力）

### 底盘约束双层体系

| 底盘（舞台本身） | 约束（剧本边界） |
|---|---|
| ① 地理层（最硬） | ⑥ 军事层（暴力约束） |
| ② 经济层 | ⑦ 制度层（最软） |
| ③ 历史层（叙事约束） | |
| ④ 文化层（行为模式） | |
| ⑤ 民族群体层（身份边界） | |

## 三个历史场景

| 场景 | 年代 | 类型 | 核心洞察 |
|------|------|------|----------|
| 🇨🇺 古巴导弹危机 | 1962 | 核威慑博弈 | 秘密交易=体面退出；核威慑的逻辑不是"谁会赢"而是"谁能承受不赢" |
| 🇮🇶 海湾战争 | 1990-91 | 常规军事博弈 | 技术革命颠覆军事预期；联盟政治决定军事上限 |
| 🇺🇦 克里米亚危机 | 2014 | 灰色地带博弈 | 低于战争门槛+西方慢决策周期=行动窗口 |

## 使用方法

1. 下载 `地缘推演台-历史回溯版V2.html`，用浏览器打开（无需服务器，单文件即用）
2. 选择一个历史场景
3. 阅读时间锁定信息，回答引导选择题（全程无需写字）
4. 走到最后一步，揭开历史对比
